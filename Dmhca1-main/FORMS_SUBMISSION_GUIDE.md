# Admin Panel Extension Guide - Forms & Submissions

## Overview

The admin panel already has the infrastructure to manage form submissions. The **applications** table serves as a general-purpose form submission handler. This guide shows how to extend it for custom forms.

---

## Current Applications Table Structure

```sql
CREATE TABLE public.applications (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id uuid NULL,
  full_name text NOT NULL,
  email text NOT NULL,
  phone text NOT NULL,
  course_name text NULL,
  program_name text NULL,
  qualification text NULL,
  experience text NULL,
  message text NULL,
  status text NOT NULL DEFAULT 'new',
  created_at timestamptz NOT NULL DEFAULT now()
);
```

**RLS Policy**: Public can insert, admins can view/update

## Architecture for Custom Forms

### Option 1: Extend Applications Table (Recommended)

**Pros**:
- Reuse existing RLS policies
- Use existing admin view
- Minimal migration needed
- Single table for all forms

**Cons**:
- Less normalized
- Query becomes more complex with multiple form types

**Implementation**:

1. **Add form_type column**
   ```sql
   ALTER TABLE public.applications 
   ADD COLUMN form_type VARCHAR(50) DEFAULT 'course_application';
   
   ALTER TABLE public.applications
   ADD CONSTRAINT form_type_check 
   CHECK (form_type IN ('course_application', 'inquiry', 'callback', 'workshop_registration', etc.));
   ```

2. **Store extra data as JSONB**
   ```sql
   ALTER TABLE public.applications 
   ADD COLUMN form_data JSONB DEFAULT '{}'::jsonb;
   ```

3. **Updated schema**
   ```
   applications:
   ├─ id
   ├─ form_type ('course_application', 'workshop', etc.)
   ├─ user_id (nullable)
   ├─ full_name, email, phone
   ├─ course_name, program_name
   ├─ qualification, experience
   ├─ message
   ├─ form_data (JSON for custom fields)
   ├─ status ('new', 'reviewed', 'accepted', 'rejected')
   └─ created_at
   ```

4. **Admin page filter by form_type**
   ```typescript
   // In admin.applications.tsx
   let query = supabaseClient
     .from('applications')
     .select('*')
     .eq('form_type', selectedFormType); // Add this
   ```

---

### Option 2: Create Separate Tables (More Flexible)

**Pros**:
- Clean separation
- Normalized design
- Can have different fields per form type

**Cons**:
- Multiple admin views needed
- More migrations required
- Separate RLS policies

**Example for Inquiry Form**:
```sql
CREATE TABLE public.inquiries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NULL,
  full_name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT NOT NULL,
  subject TEXT NOT NULL,
  message TEXT NOT NULL,
  inquiry_type VARCHAR(50), -- 'general', 'admission', 'corporate', etc.
  status VARCHAR(50) DEFAULT 'new',
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);

ALTER TABLE public.inquiries ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public inserts" ON public.inquiries
  FOR INSERT WITH CHECK (true);

CREATE POLICY "Allow users to view" ON public.inquiries
  FOR SELECT USING (true);
```

Then create separate admin page:
- [src/routes/admin.inquiries.tsx](src/routes/admin.inquiries.tsx)

## Step-by-Step: Add Custom Form Type to Applications

### 1. Create Frontend Form Component

**File**: `src/components/CustomFormModal.tsx`

```typescript
import React, { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Loader2, X } from 'lucide-react';

export function CustomFormModal({ isOpen, onClose, onSuccess, formType }) {
  const [formData, setFormData] = useState({
    full_name: '',
    email: '',
    phone: '',
    course_name: '', // Optional, depending on form
    message: '',
    // Add custom fields as needed
  });
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setError('');
    setLoading(true);

    try {
      const response = await fetch('/api/submit-form', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          form_type: formType, // e.g., 'inquiry', 'callback_request'
          ...formData,
        }),
      });

      if (!response.ok) {
        const data = await response.json();
        throw new Error(data.error || 'Failed to submit form');
      }

      onSuccess();
      onClose();
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Failed to submit');
    } finally {
      setLoading(false);
    }
  };

  if (!isOpen) return null;

  return (
    <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50 p-4">
      <div className="bg-white rounded-xl p-8 max-w-lg w-full shadow-2xl relative">
        <button
          onClick={onClose}
          className="absolute top-4 right-4 p-2 hover:bg-gray-100 rounded-full"
        >
          <X className="h-6 w-6" />
        </button>

        <h2 className="text-2xl font-bold mb-6">Contact Us</h2>

        <form onSubmit={handleSubmit} className="space-y-4">
          <div>
            <label className="block text-sm font-medium mb-2">Full Name</label>
            <Input
              type="text"
              value={formData.full_name}
              onChange={(e) =>
                setFormData({ ...formData, full_name: e.target.value })
              }
              required
            />
          </div>

          <div>
            <label className="block text-sm font-medium mb-2">Email</label>
            <Input
              type="email"
              value={formData.email}
              onChange={(e) =>
                setFormData({ ...formData, email: e.target.value })
              }
              required
            />
          </div>

          <div>
            <label className="block text-sm font-medium mb-2">Phone</label>
            <Input
              type="tel"
              value={formData.phone}
              onChange={(e) =>
                setFormData({ ...formData, phone: e.target.value })
              }
              required
            />
          </div>

          <div>
            <label className="block text-sm font-medium mb-2">Message</label>
            <textarea
              value={formData.message}
              onChange={(e) =>
                setFormData({ ...formData, message: e.target.value })
              }
              className="w-full p-2 border rounded-lg focus:ring-2 focus:ring-blue-500"
              rows={4}
              required
            />
          </div>

          {error && (
            <div className="p-3 bg-red-50 text-red-700 rounded-lg text-sm">
              {error}
            </div>
          )}

          <Button type="submit" disabled={loading} className="w-full">
            {loading ? (
              <>
                <Loader2 className="mr-2 h-4 w-4 animate-spin" />
                Submitting...
              </>
            ) : (
              'Submit'
            )}
          </Button>
        </form>
      </div>
    </div>
  );
}
```

### 2. Create API Endpoint

**File**: `api/submit-form.js`

```javascript
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  process.env.VITE_SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY
);

export async function post(req) {
  try {
    const { 
      form_type = 'inquiry',
      full_name, 
      email, 
      phone, 
      message,
      course_name,
      ...extraFields
    } = await req.json();

    if (!full_name || !email || !phone || !message) {
      return new Response(
        JSON.stringify({ error: 'Missing required fields' }), 
        { status: 400 }
      );
    }

    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      return new Response(
        JSON.stringify({ error: 'Invalid email' }), 
        { status: 400 }
      );
    }

    // Insert into applications table
    const { data, error } = await supabase
      .from('applications')
      .insert({
        form_type,        // Track which form this came from
        full_name,
        email,
        phone,
        course_name: course_name || null,
        message,
        form_data: extraFields, // Store any additional fields as JSON
        status: 'new',
      })
      .select()
      .single();

    if (error) throw new Error(`DB error: ${error.message}`);

    // Optional: Send email notification to admin
    // await sendAdminNotification(data);

    return new Response(
      JSON.stringify({ 
        ok: true, 
        message: 'Form submitted successfully',
        id: data.id 
      }),
      { status: 200 }
    );
  } catch (err) {
    console.error('submit-form error:', err);
    return new Response(
      JSON.stringify({ error: err.message || 'Server error' }), 
      { status: 500 }
    );
  }
}
```

```typescript
// Add form type filter to existing component
export function AdminApplications() {
  const [formType, setFormType] = useState('all'); // Add this
  const formTypes = ['all', 'course_application', 'inquiry', 'callback_request'];

  useEffect(() => {
    loadApplications();
  }, [formType]); // Add formType to dependency

  const loadApplications = async () => {
    try {
      let query = supabaseClient
        .from('applications')
        .select('*')
        .order('created_at', { ascending: false });

      // Add form type filter
      if (formType !== 'all') {
        query = query.eq('form_type', formType);
      }

      const { data, error } = await query;
      if (error) throw error;
      setApplications(data || []);
    } catch (error) {
      console.error('Error loading applications:', error);
    } finally {
      setLoading(false);

                : 'bg-gray-200 text-gray-700 hover:bg-gray-300'
            }`}
          >
            {type === 'all' ? 'All Submissions' : type.toUpperCase()}
          </button>
        ))}
      </div>

      {/* Existing table code */}
    </div>
  );
}
```

## Advanced: Email Notifications to Admin

### Add to submit-form.js

```javascript
import nodemailer from 'nodemailer';

const transporter = nodemailer.createTransport({
  host: process.env.SMTP_HOST,
  port: Number(process.env.SMTP_PORT || 587),
  secure: process.env.SMTP_SECURE === 'true',
  auth: {
    user: process.env.SMTP_USER,
    pass: process.env.SMTP_PASS,
  },
});

async function sendAdminNotification(formData) {
  try {
    await transporter.sendMail({
      from: process.env.SMTP_FROM,
      to: process.env.ADMIN_EMAIL, // Set this env var
      subject: `New ${formData.form_type} Submission from ${formData.full_name}`,
      html: `
        <h2>New Form Submission</h2>
        <p><strong>Type:</strong> ${formData.form_type}</p>
        <p><strong>Name:</strong> ${formData.full_name}</p>
        <p><strong>Email:</strong> ${formData.email}</p>
        <p><strong>Phone:</strong> ${formData.phone}</p>
        <p><strong>Message:</strong></p>
        <p>${formData.message.replace(/\n/g, '<br>')}</p>
        <a href="${process.env.ADMIN_URL}/admin/applications">
          View in Admin Panel
        </a>
      `,
    });
    console.log('Admin notification sent');
  } catch (err) {
    console.error('Failed to send admin notification:', err);
    // Don't throw - don't fail the form submission if email fails
  }
}

// In post handler, after insert:
if (data) {
  await sendAdminNotification(data);
}
```

## Database Migration Script

**File**: `migrations/012_add_form_types.sql`

```sql
-- Add form_type and form_data columns to applications
ALTER TABLE public.applications
ADD COLUMN IF NOT EXISTS form_type VARCHAR(50) DEFAULT 'course_application';

ALTER TABLE public.applications
ADD COLUMN IF NOT EXISTS form_data JSONB DEFAULT '{}'::jsonb;

-- Add constraint
ALTER TABLE public.applications
DROP CONSTRAINT IF EXISTS form_type_check;

ALTER TABLE public.applications
ADD CONSTRAINT form_type_check 
CHECK (form_type IN (
  'course_application', 
  'inquiry', 
  'callback_request',
  'workshop_registration',
  'general_inquiry'
));

-- Create index for faster filtering
CREATE INDEX IF NOT EXISTS idx_applications_form_type 
ON public.applications(form_type);

CREATE INDEX IF NOT EXISTS idx_applications_form_type_status 
ON public.applications(form_type, status);
```

## Extending Further: Multiple Form Types

### Create a Form Registry

**File**: `src/utils/forms.ts`

```typescript
export const formRegistry = {
  inquiry: {
    title: 'General Inquiry',
    fields: ['full_name', 'email', 'phone', 'message'],
  },
  callback_request: {
    title: 'Request Callback',
    fields: ['full_name', 'email', 'phone', 'preferred_time'],
  },
  course_application: {
    title: 'Course Application',
    fields: ['full_name', 'email', 'phone', 'course_name', 'qualification', 'experience'],
  },
  workshop_registration: {
    title: 'Workshop Registration',
    fields: ['full_name', 'email', 'phone', 'workshop_date', 'specialization'],
  },
};

export function getFormConfig(formType: string) {
  return formRegistry[formType] || formRegistry.inquiry;
}
```

### Dynamic Form Builder

```typescript
function DynamicFormBuilder({ formType, onSubmit }) {
  const config = getFormConfig(formType);
  
  return (
    <form onSubmit={onSubmit}>
      {config.fields.map(field => (
        <DynamicField key={field} fieldName={field} />
      ))}
    </form>
  );
}
```
